# Article typography

The reference article uses Iowan Old Style BT for prose and GT America for interface text. `typography.css` prefers these families when installed on the reader's device; their commercial font files are not bundled.

Self-hosted fallbacks:

| Family | File | Source | License |
| --- | --- | --- | --- |
| Source Serif 4 | `source-serif-4-latin.woff2` | [Google Fonts](https://fonts.google.com/specimen/Source+Serif+4) / [Adobe](https://github.com/adobe-fonts/source-serif) | `source-serif-4-OFL.txt` |
| Inter | `inter-400-800.woff2` | [Inter](https://rsms.me/inter/) | `inter-OFL.txt` |

Chinese glyphs use installed serif or sans-serif CJK families according to the text's role. Fallbacks are not claimed to be exact reproductions of the reference fonts. Existing Inter Tight and DM Mono files remain available for older project assets but are not used by the article stylesheet.
