# DuckGo Blog

为了测试通用 Agent 的机器人控制能力，我们在 MuJoCo 中设计了一场障碍赛，让 Agent 驾驶双足机器人 Microduck 挑战 16 个检查点。博客记录了单人试跑和多 Agent 同场竞速的成绩与发现。

[中文博客](https://phygital-ai.github.io/DuckGo-Blog/?lang=zh) · [English blog](https://phygital-ai.github.io/DuckGo-Blog/?lang=en) · [竞赛代码](https://github.com/HandsomeWuuu/DuckGO) · [在线体验](https://huggingface.co/spaces/HandsomeWu666/DuckGO)

## 本地预览

使用 Node.js 22.12 或更高版本运行：

```sh
npm ci
npm run dev
```
