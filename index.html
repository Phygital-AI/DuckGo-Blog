01 / RESEARCH QUESTION

From an image to a decision. From a command to an uncertain outcome.

When skill outcomes are not guaranteed, and the world keeps changing while an agent thinks, can a general-purpose agent use first-person observation and replanning to bring a simulated robot through an entire obstacle race?

WHAT IS EVALUATEDThe complete agent, not a single model response.

The model is its reasoning core. The agent must observe, call skills, interpret feedback and remain in control until the referee ends the run.

NOT NAVIGATION ALONENOT A JOINT-TORQUE BENCHMARK
02 / THE CHALLENGE

The plan is not the trajectory.

The agent selects a skill. The robot and the moving course determine where it actually goes. Each new view can demand a different decision.

ONE SKILL / MANY POSSIBLE OUTCOMES

The same call can end differently.

A skill specifies what to attempt, not a guaranteed path. Obstacle phase, contact, momentum and balance shape the motion that follows.

WHAT THE AGENT MUST DOObserve the actual outcome, then decide again.
01 / SEE

Partial view

Infer the route and obstacle state from the robot's own camera.

02 / DECIDE

A changing world

In real time, the opportunity may move while the agent thinks.

03 / ACT

Uncertain execution

Skills meet contacts, momentum, balance limits and moving obstacles.

04 / CONTINUE

Recovery and control

Detect stalls, falls and drift; recover and keep going until the referee ends the race.
